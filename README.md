# BLUTRACE AI frontend prototype

Static, dependency-free demonstration UI for SIH26057. It uses mock analysis data deliberately so it can later be connected to the Python/ML inference service.

## Run locally

From this folder, run:

```powershell
node serve.js
```

Then open `http://localhost:8080`.

The demo flow is: upload → processing → detection/validation → geolocation → downloadable report.
